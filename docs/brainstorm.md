# 모두의 한국어 — 브레인스토밍

> 상태: 발산 단계. 이 문서는 결정문이 아니다. 결정된 내용은 `product-brief.md`에 옮긴다.

## 한 문장들

- 한국어를 공부시키는 앱이 아니라, **내일 한국어로 살아야 하는 순간을 오늘 먼저 살아보게 하는 앱**.
- 교재의 진도가 아니라 **사용자의 내일**이 수업 순서를 정한다.
- 번역을 보여주는 것을 넘어, 사용자가 **자기 목소리로 말할 수 있게** 만든다.
- 오늘의 10분 연습이 내일의 한마디가 된다.

## 해결하려는 긴장

| 지금 | 바꾸려는 상태 |
|---|---|
| 피곤한 퇴근 뒤, 교재를 처음부터 펴야 한다 | 내일 필요한 한 장면만 10분 동안 연습한다 |
| 번역기를 보여 주거나 가족에게 대신 부탁한다 | 먼저 혼자 말해 보고, 필요한 도움만 받는다 |
| 틀릴까 봐 실제 대화를 미룬다 | AI 앞에서 먼저 틀리고, 다시 말한다 |
| 모든 발음을 한꺼번에 고치려 한다 | 내일의 대화에 영향을 주는 두 발음만 고친다 |

## 첫 사용자

**일과 가정을 병행하는 이주민 부모.**

다음 달부터 아이 학원을 두 달 쉬고 다시 다니고 싶다는 결정을 학원에 전달해야 한다. 무슨 뜻인지는
알지만, 전화에서 기간과 재연락 시점을 바로 묻기 어렵다. 가족에게 대신 말해 달라고 하거나 번역기를
읽는 방식에 의존하고 싶지도 않다.

이 사용자는 초급자만을 뜻하지 않는다. 오래 한국에 살았어도, 낯선 상황·존댓말·발음 때문에 실제
대화 앞에서 자신감이 낮을 수 있다.

## 사용 장면 후보

| 장면 | 사용자가 이루려는 일 | drama | 첫 demo 적합도 |
|---|---|---:|---:|
| 자녀 교육 | 학원 휴원·재등록·학교 상담을 직접 전달한다 | 높음 | **최우선** |
| 병원 | 증상을 설명하고 질문에 답한다 | 높음 | 높음 |
| 직장 | 휴무·교대·급여를 묻는다 | 높음 | 중간 |
| 집 | 집주인에게 고장·계약 문제를 말한다 | 중간 | 중간 |
| 동네 | 주민센터·은행에서 필요한 일을 말한다 | 중간 | 낮음 |

첫 demo 는 **학원 두 달 휴원과 재등록 연락 시점 문의**로 고정한다. 단순한 학원 이용 불편이 아니라,
보호자가 자녀 교육 결정을 자기 목소리로 전달하지 못해 가족이나 번역기에 의존하는 순간을 보여 준다.

## 제품의 핵심 loop

### A. 내일 카드

사용자가 자기 언어 또는 쉬운 한국어로 말한다.

`다음 달부터 두 달 동안 아이 학원을 쉬고 싶어요. 다시 다니려면 언제 연락해야 하나요?`

AI는 이를 역할·목표·상대·난이도로 바꾼다.

- 상대: 학원 선생님
- 목적: 두 달 휴원과 재등록 연락 시점 문의
- 반드시 말할 것: 다음 달 시작, 두 달, 다시 다닐 의사
- 예상 질문: 완전히 그만두는지, 잠시 쉬는지

### B. 먼저 말해 보기

AI가 상대 역할로 첫 질문을 한다. 사용자는 한국어로 답한다. 멈추거나 모국어를 섞어도 대화가
끊기지 않는다.

### C. 한 번에 두 가지만

대화가 끝나면 “틀린 것 20개”가 아니라, 내일의 전달력을 가장 크게 높일 표현·발음 두 개만 보여 준다.

- 더 쉬운 문장 하나
- 반복된 발음 혼동 하나

### D. 같은 상황을 다시

AI가 같은 역할극을 더 짧게 다시 시작한다. 사용자는 수정한 문장을 바로 말한다.

### E. 내일 카드로 끝

사용자는 세 문장, 예상 질문 하나, 발음 팁 하나만 들고 나간다.

## interaction 아이디어

| 이름 | 설명 | 가치는 무엇인가 |
|---|---|---|
| **내일 카드** | 다음 날의 일을 한 문장으로 넣으면 연습 장면을 연다 | 교재 선택 부담을 없앤다 |
| **말 막힘 버튼** | 대화 중 누르면 모국어·쉬운 한국어·짧은 힌트 중 하나를 준다 | 실수해도 대화가 멈추지 않는다 |
| **두 소리만** | 세션별 핵심 발음 두 개만 고른다 | 피드백 과부하를 막는다 |
| **속도 다이얼** | 상대방 말하기 속도를 천천히·보통·실전으로 바꾼다 | 실제 통화에 단계적으로 가까워진다 |
| **다시 말하기** | 첫 시도와 두 번째 시도를 나란히 남긴다 | 사용자가 변화 전후를 직접 듣는다 |
| **내일 문장 세 개** | 역할극 끝에 실행용 카드만 남긴다 | 학습이 아니라 행동으로 끝난다 |
| **상황 사진** | 가정통신문·예약 문자 사진에서 연습 상황을 만든다 | 실제 생활과 제품을 바로 연결한다 |

`상황 사진`은 매력적이지만 첫 60초 demo 에서 필수는 아니다. 텍스트 입력 하나로 먼저 닫는다.

## 개인화의 경계

**사용할 것**

- 주사용 언어
- 사용자가 직접 말한 목표
- 실제 발화에서 반복된 혼동
- 사용자가 선택한 난이도와 말하기 속도

**사용하지 않을 것**

- 국적만으로 특정 발음 오류를 단정하는 규칙
- 한 번의 녹음만으로 한국어 실력을 전반 평가하는 점수
- 발음 완벽도를 성공 기준으로 삼는 방식

성공은 `원어민처럼 말함`이 아니라 **내일 상대방에게 목적을 전달함**이다.

## LLM이 하는 일과 하지 않는 일

| LLM이 해야 하는 일 | LLM이 하면 안 되는 일 |
|---|---|
| 생활 언어의 목표를 대화 장면으로 재구성 | 법률·의료 판단을 대신하기 |
| 사용자의 답에 따라 다음 질문과 힌트를 바꾸기 | 근거 없이 발음·실력을 단정하기 |
| 모국어 뜻과 쉬운 한국어 사이를 연결하기 | 긴 교재·문법 설명을 쏟아내기 |
| 대화에서 가장 중요한 두 가지를 요약하기 | 모든 오류를 채점표처럼 나열하기 |

## 화면·연출 후보

### 1. 전화 리허설

화면 전체가 전화 통화처럼 보인다. 상단에는 `학원 선생님과 통화 연습`, 중앙에는 AI와 사용자의
대화, 하단에는 큰 microphone 하나만 있다. 가장 직관적이고 demo 에 강하다.

### 2. 대화극 카드

AI가 선생님·의사·사장님 카드로 등장하고, 사용자는 선택지를 고르거나 말한다. 이해는 쉽지만
일반 언어 학습 앱처럼 보일 위험이 있다.

### 3. 내일의 일정표

내일 일정 한 칸을 누르면 그 상황의 대화를 연습한다. 제품 확장성은 좋지만 첫 demo 의 감정은 약하다.

**권장: 1번 전화 리허설.** 실제로 말하기가 두렵다는 긴장을 화면 자체로 보여 준다.

## 60초 demo 후보 대본

| 시간 | 장면 | 관객이 알아야 할 것 |
|---:|---|---|
| 0–8초 | `다음 달부터 두 달 동안 아이 학원을 쉬고 싶어요. 다시 다니려면 언제 연락해야 하나요?` 입력 | 이 앱은 실제 교육 결정에서 출발한다 |
| 8–15초 | `학원 선생님 · 두 달 휴원 · 재연락 문의`가 자동 생성 | LLM이 목표를 대화로 바꾼다 |
| 15–32초 | 선생님 역할 AI가 질문, 사용자가 첫 답변 | 실제로 말하는 연습이다 |
| 32–42초 | `오늘은 이 표현과 이 발음만` 피드백 | 개인화가 짧고 선명하다 |
| 42–54초 | 같은 질문에 두 번째 답변 | 전후 변화가 보인다 |
| 54–60초 | 내일 문장 세 개 카드 | 사용자는 바로 쓸 것을 들고 간다 |

## 3분 30초 발표에서 쓸 수 있는 대비

| 기존 한국어 학습 | 모두의 한국어 |
|---|---|
| 교재가 오늘의 수업을 정한다 | 사용자의 내일이 오늘의 수업을 정한다 |
| 단어·문법을 넓게 쌓는다 | 한 상황을 실제로 끝낸다 |

| 혼자 듣고 본다 | 상대 역할과 실제로 말한다 |
