# 내일의 한국어 — AI 교정 스펙

## 목적과 범위

사용자가 중국어 음성으로 말한 내일의 생활 상황을 바탕으로, AI가 한국인 상대 역할로
역할극을 연다. 사용자의 한국어 음성 답변에는 **어휘·문법**과 **발음**을 분리해 즉시
피드백하고, 사용자가 같은 턴을 다시 말할 수 있게 한다.

첫 데모의 사용자는 표준 만다린 간체자(`zh-CN`)를 주사용 언어로 하는 이주민 부모이며, 장면은 담임에게
아이의 결석을 알리는 연락이다. 성공은 원어민 같은 발음이 아니라 상대에게 목적을
정확히 전달하는 것이다.

이 문서는 로그인, 학습 이력, 사용자 등급, 발음 완벽도 판정, 국적만으로 한 오류 추정은
범위에서 제외한다.

## 공통 흐름

1. 사용자가 중국어 음성으로 내일의 상황을 말한다.
2. AI는 번역만 하지 않고 조퇴/결석, 연락 수단처럼 의미나 한국의 대화 맥락이 갈리는
   부분을 중국어로 확인한다.
3. AI는 상대, 목적, 필수 정보, 예상 질문을 포함한 역할극 장면을 생성한다.
4. AI가 한국인 상대 역할로 한국어 질문을 한다.
5. 사용자가 실제 마이크로 한국어로 답한다.
6. 서비스는 같은 발화에서 어휘·문법과 발음 피드백을 분리해 즉시 보여준다.
7. 사용자는 교정된 완성 문장을 실제 음성으로 다시 말하거나 다음 질문으로 넘어간다.
8. 재시도 발화는 같은 목표 문장을 기준으로 새로 발음 채점한다. 마지막에는 바로 쓸
   문장과 방금 배운 점만 짧게 정리한다.

## 입력과 분석 경계

### AI가 받는 근거

- 중국어 원래 발화의 목적과 상황 확인 결과
- 현재 역할극의 상대, 목표, 필수 정보, AI의 직전 질문
- 사용자의 실제 한국어 음성과 한국어 전사
- 재시도 시의 목표 한국어 문장

### 판정 원칙과 제외 범위

- 표준 만다린 화자에게 자주 나타나는 발음 패턴을 참고하되, 실제 발화에서 확인된 항목만 교정한다.
- 한 발화로 사용자의 전체 한국어 능력을 등급화하지 않는다.
- 의료·법률·학교 규정을 판단하거나 조언하지 않는다.

## 축 1 — 어휘·문법 교정

### 판정 대상과 우선순위

교정은 사용자가 실제로 말한 문장에만 적용한다. 아직 말하지 않은 정보는 오류로
처리하지 않고, AI 상대가 다음 턴에 자연스럽게 묻는다.

1. **뜻이 달라지는 어휘·문화 맥락 오류**: 조퇴/결석처럼 상대의 행동이나 이해를
   바꿀 수 있는 표현
2. **목적 전달을 흐리는 문법·정보 오류**: 시제, 이유, 날짜, 주어 등이 달라지는 경우
3. **상대에 맞지 않는 문체**: 담임·의사·고용주에게 필요한 존댓말과 요청 방식
4. **더 자연스러운 표현**: 의미는 전달되지만 실제 상황에서 더 자연스러운 표현

개수 상한은 두지 않는다. 여러 항목이 있으면 위 우선순위 순으로 보여 주며, 피드백은
사용자가 다시 말할 하나의 완성 문장으로 합친다.

### UI 규칙

이 축에는 다음 정보를 각 항목마다 보인다.

- 우선순위 라벨: `뜻이 달라져요`, `더 공손하게 말해요` 등
- `내가 말한 문장`
- `이렇게 말해 보세요`: 수정된 한국어
- `中文说明`: 수정 이유와 의미 차이
- `천천히 듣기`, `이 문장으로 다시 말하기`, `다음으로` 동작

한국어 목표 문장은 크게 보여 주고, 이유와 차이는 중국어로 설명한다.

## 축 2 — 발음 교정

### 판정 대상과 원칙

발음은 실제 한국어 음성과 목표 문장을 함께 근거로 판정한다. 첫 발화에서 전달이
약하게 들린 단어를 후보로 잡되, 근거가 불충분하면 오류를 만들어 내지 않는다.

사용자가 교정 문장을 다시 말하면, 그 새 음성을 **같은 목표 문장**으로 다시 채점한다.
다른 표현으로 바꾸면 새 표현을 확인한 뒤 새 목표 문장과 첫 점수로 시작한다.

점수는 사용자의 한국어 실력, 등급, 합격 여부가 아니다. 해당 문장을 상대가 알아듣기
쉽게 말했는지를 나타내는 일회성 `발음 전달도`다.

### UI 규칙

- `발음 전달도 68점 · 한 번 더 연습해볼 수 있어요`처럼 숫자와 상태 문구를 함께 표시
- 연습할 완성 문장과 집중 단어를 표시
- 중국어로 소리 연결, 받침, 말하기 순서를 안내
- `천천히 듣기`, `내 발음 다시 듣기`, `다시 말하기`, `다음으로` 동작
- 점수와 무관하게 다음 질문으로 갈 수 있다.

상태 문구는 다음과 같이 고정한다.

| 점수 | 상태 문구 |
| --- | --- |
| 85–100 | 매우 또렷하게 전달됐어요 |
| 70–84 | 또렷하게 전달됐어요 |
| 50–69 | 전달 가능해요. 한 번 더 연습할 수 있어요 |
| 0–49 | 천천히 한 번 더 말해볼까요? |

재시도 뒤에는 `이전 68점 → 이번 76점`처럼 같은 문장의 변화만 비교한다.

## 두 축의 동시 표시와 재시도

한국어 답변을 분석한 직후 UI를 두 영역으로 분리한다.

| 어휘·문법 교정 | 발음 교정 |
| --- | --- |
| 사용자 문장, 추천 표현, 중국어 이유 | 전달도 점수, 집중 단어, 중국어 발음 안내 |

사용자가 `이 문장으로 다시 말하기`를 누르면 어휘·문법 교정 사항을 반영한 **하나의
완성 문장**이 녹음 목표가 된다. 재시도 음성은 이 완성 문장으로 발음 전달도를 갱신한다.
의미가 잘못 전달되는 경우에는 재시도를 명확히 권하지만, 어떤 점수도 대화를 강제로
막지 않는다.

## 실패 시 동작

- 중국어 또는 한국어 음성이 전사되지 않으면, 결과를 추측하지 않고 짧은 녹음 재시도
  안내를 보인다.
- 발음 분석 근거가 부족하면 특정 오류를 단정하지 않고 발음 상세 교정을 생략한다.
- 역할극에 필요한 정보가 빠졌으면 오류 카드가 아니라 상대 역할의 다음 질문으로 받는다.
- 피드백 생성이 실패하면 마지막으로 확인된 역할극 문맥과 사용자 전사를 보존하고,
  재시도 안내를 제공한다.

## 데모 검증 시나리오

1. 중국어 음성으로 `아이가 아파서 내일 학교에 가지 못한다`는 의도를 입력한다.
2. AI가 조퇴/결석 등 의미 갈림을 중국어로 확인하고, 담임 연락 장면을 만든다.
3. 사용자가 한국어로 첫 답변을 녹음한다.
4. 두 교정 UI가 즉시 분리되어 표시되고, 어휘·문법 교정은 하나의 완성 문장을 제시한다.
5. 사용자가 그 문장을 다시 녹음하면 발음 전달도가 새 점수로 갱신되며 이전 점수와
   비교된다.
6. 사용자가 다음 질문으로 넘어가고, 짧은 마무리 요약을 본다.
