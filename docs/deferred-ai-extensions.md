# 보류한 AI·NLP 확장안

기본 1회전(음성 전사 → 장면 → 첫 답변 점수·교정 → 재시도 점수)이 안정적으로 동작한 뒤에만 검토한다.

## 1. Kiwi 기반 의미 슬롯 근거

- 목적: ASR 전사에서 `아이의 아픔`, `내일`, `학교 결석`을 형태소·어간 기준으로 확인하고, 점수 옆에 인식된 근거를 보여 준다.
- 현재 보류 이유: `school_absence`의 v1 계약은 형태소 분석 없이 명시 표면형을 판정하도록 잠겨 있다. 60초 데모의 점수 산식을 바꾸면 기존 fixture 검증이 무효가 된다.
- 재개 조건: 실제 ASR 전사 10건 이상에서 단순 표면형 매처가 의미를 놓친 사례를 수집했을 때. 기존 예시와 새 예시 모두에서 점수 변화를 표로 검증한다.
- 경계: 형태소 분석은 의미 슬롯 판정의 보조 근거만 담당한다. 음소·억양·한국어 실력 등급을 추정하지 않는다.

## 2. 로컬 Qwen 기반 중국어 장면 코칭

- 목적: 중국어 상황 해석과 중국어 확인 질문을 로컬에서 생성해 외부 코칭 API 의존도를 줄인다.
- 현재 보류 이유: 모델 다운로드, 로컬 서빙, 출력 JSON 검증이 60초 데모의 안정성·준비 시간을 늘린다. 현재 계약은 fixture 폴백으로 키 없이도 동일 UI 흐름을 보장한다.
- 재개 조건: OpenAI 코칭 호출의 네트워크 지연·비용·개인정보 제약이 실제 사용자 테스트에서 병목으로 확인됐을 때. 같은 10개 중국어 상황에서 OpenAI 응답과 JSON 유효성·사실 추가 여부·응답 시간을 비교한다.
- 경계: Qwen 출력도 발음 점수나 실제로 듣지 못한 음소 오류를 만들 수 없다. 점수는 계속 결정적 STT 전사 규칙으로 산출한다.
